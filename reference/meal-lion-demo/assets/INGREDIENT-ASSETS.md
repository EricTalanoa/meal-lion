# Ingredient asset collection 01

Generated with the built-in image-generation tool using the original chef-poses.png as the identity reference. Originals are preserved at generated resolution.

- ingredients.png: 3 columns × 2 rows. Tomato, egg, bell pepper / onion, cumin, paprika.
- leo-onion.png: 4 equal-width columns. Present onion / slice / slice with tears / wipe eye.
- leo-tomato.png: 4 equal-width columns. Present tomato / prepare knife / slice / show plate.
- leo-egg.png: 4 equal-width columns. Present egg / tap / crack / celebrate.

Open ../ingredients.html for timed key-pose previews. All frames remain in their original sheets; CSS background positioning and canvas source rectangles select frames without altering the originals.

These are draft key poses, not final smooth sprite animations. Tables, hat silhouettes and body positioning vary slightly between generated frames. Before production, align landmarks and add intermediate chopping frames. The onions' tears are drawn into poses 3 and 4; they are not separate tear particle assets yet. Pepper and spice interactions are not included in this first set.
