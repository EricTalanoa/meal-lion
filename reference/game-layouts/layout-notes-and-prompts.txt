Keyboard should collapse stage and keep input visible. These are layout proposals, not tested responsive screens.

Use same action model across desktop and phone. Custom ingredient animation plays in a fixed stage without pushing controls around. Order of sample reveals and history is illustrative; do not treat the screenshots as final game state data.

User preference: more ingredients should receive custom interactions rather than generic drops. Prioritize flour puff, milk pour, butter melt, cheese grate/pull, pepper deseed and garlic crush after onion/tomato/egg. These additional animations have not been generated in this layout task.
