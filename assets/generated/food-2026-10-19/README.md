# Food artwork — 2026-10-19

Individual draft assets generated with the built-in image generation tool, following the approved existing pixel-food style. Original reference art remains untouched. Each PNG uses a one-cell (1 × 1, index 0) map entry. No generated image is production-approved merely because it exists.

`prompts.json` records exact generation prompts. Accepted images are visually inspected before mapping; alpha and publish copies are checked at each checkpoint. Run `node tools/update-food-coverage.cjs` and `python tools/optimize-images.py` after adding mapped assets, then `node --test tests/*.test.mjs`.
